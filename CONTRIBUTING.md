# Contributing

Thanks for your interest in contributing! Please follow these steps:

1. Fork the repository and create a feature branch from `main`.
2. Run `npm install` and follow `SETUP.md` to configure local environment.
3. Run `npm run lint` and `npm run test` before opening a PR.
4. Ensure changes include tests where applicable.
5. Open a PR and fill the template.

For major changes, please open an issue first to discuss.
